# Imsil FMF catalog (final)

`imsil_fmf_catalog.csv`: 235 template-matching detections (28 reference events, 207 new), 2025-09-01 to 2026-01-31, from the grid-aligned FMF code at 10 x MAD without an absolute CC floor (decisions D11, D12, D13, D20, D23 in `docs/decisions.csv`). Settings and input hashes are in `settings.json`. Evidence: notebooks 06 (frozen vs aligned), 07 (detection examples), 08 (vetting), 09 (thresholds).
