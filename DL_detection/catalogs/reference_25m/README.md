# Imsil 25 m reference catalog

`DL_reference_25m.csv` holds the 28 of 34 relocated DL events whose bootstrap 95 % half-widths in east, north and depth are all finite and at most 25 m (the Haenam reference rule). No other location selection applies. `DL_all_with_uncertainty.csv` lists every relocated event with its half-widths and the reason for exclusion. Inputs and their hashes are in `selection_manifest.json`. Built by `catalogs/build_reference_25m.py`.
